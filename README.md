Sobre Fast Executable:

FastExecutable es una herramienta que permite convertir archivos `.py` a `.exe` de forma rápida desde el editor Cobra Python.

## Uso
1. Abrir el **Cobra Python Editor**.
2. Ir a la sección **Python Reusables** y seleccionar FastExecutable V2526.
3. Guardar el archivo si deseas usarlo fuera del editor.
4. Presionar **Ejecutar**.
5. Seleccionar **Convertir a .exe**.
6. Seguir el progreso en la consola integrada.
7. Al finalizar, el archivo `.exe` se encontrará en la carpeta `dist` dentro del directorio del script.

## Recomendaciones
- No cierres la ventana del editor durante la conversión.
- Asegúrate de tener instalado Python y PyInstaller.
